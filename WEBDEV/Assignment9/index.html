Responsive Design Explained

Responsive design adapts layouts and media to different screen sizes using flexible grids, fluid media, and breakpoints. Key techniques: flexible units (%, rem), CSS Grid/Flexbox, responsive images, and thoughtfully chosen breakpoints.

  • Use mobile-first media queries.
  • Prefer relative sizing for spacing and fonts.
  • Test breakpoints at real device widths.

Cheat Sheet

.container { padding: 1rem; }
@media (min-width:700px) { .combined-grid { grid-template-columns: 1.2fr 1fr; } }

Responsive Design Principles

Fluid Layouts

Layouts that use relative widths so content flows across viewports.

.col { width: 100%; max-width: 600px; }

Flexible Media

Images and video scale: max-width:100%; height:auto;

img { max-width:100%; height:auto; }

Breakpoints

Strategically chosen widths to change layout patterns.

@media (min-width:700px) { /* layout */ }
