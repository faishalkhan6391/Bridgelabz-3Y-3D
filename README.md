## 🧩 Topics Covered

### CSS Grid Layout
A two-dimensional layout system that allows developers to structure webpages using **rows and columns**, providing advanced alignment and spacing control.

#### Grid Container Properties
- `display: grid | inline-grid` – Defines the grid container.  
- `grid-template-columns`, `grid-template-rows` – Defines columns and rows.  
- `grid-template-areas` – Creates named grid areas for layouts.  
- `column-gap`, `row-gap`, `gap` – Controls spacing between grid items.  
- `justify-items`, `align-items`, `place-items` – Aligns items within grid cells.  
- `justify-content`, `align-content`, `place-content` – Aligns the entire grid inside its container.  
- `grid-auto-rows`, `grid-auto-columns`, `grid-auto-flow` – Defines auto-placement behavior.

#### Grid Item Properties
- `grid-column-start`, `grid-column-end`, `grid-row-start`, `grid-row-end` – Sets start and end positions.  
- `grid-column`, `grid-row` – Shorthand for positioning.  
- `grid-area` – Assigns grid items to specific named areas.  
- `justify-self`, `align-self`, `place-self` – Aligns individual grid items.

---

### Flexbox Layout
A one-dimensional layout model designed to align and distribute elements efficiently, even when their sizes are unknown or dynamic.

#### Flex Container Properties
- `flex-direction` – Sets the main axis direction.  
- `justify-content` – Aligns items along the main axis.  
- `align-items` – Aligns items along the cross axis.  
- `flex-wrap` – Allows items to wrap into multiple lines.  
- `align-content` – Aligns rows when there’s extra space in the cross axis.

#### Flex Item Properties
- `flex-grow` – Defines how much an item can grow.  
- `flex-shrink` – Defines how much an item can shrink.  
- `flex-basis` – Defines the base size of an item.  
- `flex` – Shorthand for grow, shrink, and basis.  
- `order` – Changes the order of items.  
- `align-self` – Overrides the container’s alignment for a single item.

---

## ⚖️ Grid vs Flexbox Comparison

| Feature | CSS Grid | Flexbox |
|----------|-----------|---------|
| Layout Type | Two-dimensional (rows & columns) | One-dimensional (row **or** column) |
| Alignment | Horizontal & vertical | Single-axis alignment |
| Best For | Page-level layouts | Component-level layouts |
| Structure | Grid-based and fixed | Flexible and content-based |
